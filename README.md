# B站点选验证码自动处理工具

本项目使用 Selenium 模拟浏览器操作，结合 **ddddocr** 和第三方打码 API（jfbym.com）自动识别并完成 Bilibili 登录过程中的点选验证码（极验行为验证）。适合用于自动化测试、爬虫登录等场景。

## 功能特点

- 自动打开 B站 登录页面并输入账号密码
- 截取验证码提示文字、背景图片和完整验证码区域
- 使用 ddddocr 识别提示文字（如“请点击图片中的 XX”）
- 将背景图片 Base64 编码后发送至第三方 API，获取各点击坐标
- 模拟鼠标点击坐标位置，自动完成验证
- 全程无头可选（当前为有头模式，便于调试）

## 环境要求

- Python 3.7+
- Chrome 浏览器（与 chromedriver 版本匹配）
- 网络可访问 https://www.bilibili.com 和 http://api.jfbym.com

## 注意事项

- 该项目仅用于演示，请勿私自使用。
- 本工具仅用于学习和研究目的，请勿用于非法或侵犯他人权益的行为。
- 第三方 API 服务为付费服务，请自行注册并获取 token。
- 验证码图片和坐标可能因 B站 更新而变化，如失效需调整相应 XPath 或 API 类型。
- 建议在稳定的网络环境下运行，避免因加载缓慢导致超时。
